# A-FIX-1: критичні залежності UI

Дата: 13 жовтня 2026 року. Unity 6000.4.7f1, Windows Editor, робоча копія без нового коміту або release build.

## Зміни

- `SceneRoleLookup` обмежує пошук конкретною сценою та відхиляє дубльовані ролі. Нові значення `SceneRole` додані наприкінці enum, старі числові значення збережено.
- Ролі полів кісток і швидкості використовуються відпочинком та виснаженням; портрет, основна сторінка й оверлеї також мають ролі.
- `UiControlMarker` визначає комірки та контролі інвентарю, кнопки й заголовки сторінок. Індекси кнопок не залежать від назв; ключі комірок і порядок ієрархії не змінені.
- `ToggleSequenceConfig` зберігає посилання на перемикачі в попередньому порядку. `ResourceToggleMarker` зберігає номер ресурсу для відпочинку й мапінгу старих сейвів.
- `HealthBarView` кешує початковий `fillRect`, який Unity Slider більше не контролює після першого рендеру. Повторний рендер не обирає інший Image за назвою.
- `OverlayBoundsFitter` використовує роль та серіалізований `mapBounds`; fallback обмежений його сценою. Наявні до задачі зміни панорамування й фону збережено.
- `MainMenuSceneLookup`, `SceneLocalizationApplier` і `WildShapeTitleUpdater` більше не перебирають завантажені assets через `Resources.FindObjectsOfTypeAll`; меню обмежене активною сценою.
- `SceneRoleMigration` і `UiDependencyMigration` перевіряють ролі, контролі, дублікати індексів та цілісність посилань груп. Міграція не починається за наявності незбережених сцен.

Міграцію виконано в живому редакторі для `cartaPersonaj`, `Spels`, `spelBook`, `inventory`, `informForPerson`, `petsesn`. Файли сцен не редагувалися вручну. Legacy fallback збережено для немігруваних сцен; формат даних не змінено.

## Перевірки
