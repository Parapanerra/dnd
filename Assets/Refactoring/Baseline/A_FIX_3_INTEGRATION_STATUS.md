# A-FIX-3: PlayMode та інтеграційні тести

Дата: 13 жовтня 2026 року. Unity 6000.4.7f1, Windows Editor.

Створено окрему `TaruckShip.PlayModeTests` assembly. Автоматична серія завантажує `cartaPersonaj`, `Spels`, `spelBook`, `inventory`, `informForPerson`, `petsesn` і перевіряє відсутність missing scripts, наявність обов'язкових ролей, повноту та унікальність стабільних ID.

Серія створює двох персонажів, перевіряє ізоляцію даних між сценами та після дискового round-trip, реальне відновлення предмета із зображенням у комірці інвентарю, HP, тимчасові HP, death saves, виснаження, заклинання й дику форму. Окремо перевіряються reset однієї сім'ї сторінок зі збереженням спільного портрета й іншої сторінки, тривалий відпочинок, merge/replace колекції, імпорт одного персонажа та незмінність поточної колекції після помилки запису.

Результат: **3/3 PlayMode**, **127/127 EditMode**, без пропусків і невдалих тестів. PlayMode виконувався з окремим `persistentDataPath` через тимчасове ім'я продукту. Початкове ім'я продукту та сцена `cartaPersonaj` відновлені; тестові дані не потрапили до робочого сейву.

Системний Android file picker, Windows build та Android APK залишаються A-FIX-4. Під час спроби використати меню як проміжну сцену Unity повідомила про неіснуюче кореневе посилання `fileID: 564821555` у `Assets/Scenes/menu.unity`. Сцена меню не входить до шести основних сцен цієї серії; тест переходить між персонажами через `Spels`. Меню не змінювали.
